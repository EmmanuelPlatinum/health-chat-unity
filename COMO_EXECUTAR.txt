🚀 COMO EXECUTAR O PROJETO NO CURSOR
================================================================================

PASSO 1: ABRIR O TERMINAL NO CURSOR
□ Clique em "Terminal" no menu superior
□ Ou use o atalho: Ctrl + ` (backtick)
□ Ou vá em View > Terminal

PASSO 2: NAVEGAR PARA A PASTA DO PROJETO
□ Digite: cd Clinica_de_saude
□ Pressione Enter

PASSO 3: INSTALAR DEPENDÊNCIAS (se necessário)
□ Digite: npm install
□ Pressione Enter
□ Aguarde a instalação terminar

PASSO 4: EXECUTAR O PROJETO
□ Digite: npm run dev
□ Pressione Enter
□ Aguarde aparecer "Local: http://localhost:8080"

PASSO 5: ABRIR NO NAVEGADOR
□ Clique no link que apareceu no terminal
□ Ou abra o navegador e vá para: http://localhost:8080

⚠️ SE DER ERRO
================================================================================

ERRO: "npm não é reconhecido"
□ Instale o Node.js: https://nodejs.org
□ Reinicie o Cursor
□ Tente novamente

ERRO: "package.json não encontrado"
□ Certifique-se de estar na pasta Clinica_de_saude
□ Use: cd Clinica_de_saude

ERRO: "porta já está em uso"
□ Feche outros projetos que estejam rodando
□ Ou use: npm run dev -- --port 3001

ERRO: "Supabase não configurado"
□ O sistema funcionará mesmo sem Supabase
□ Use as credenciais de teste acima
□ Para funcionalidade completa, configure o Supabase
